Go to the **[Releases](../../releases)** page and download the file for your device.

### Windows
1. Download `Setup.exe`.
2. Double-click to install.
3. Open from the Desktop shortcut.  
   *If Windows SmartScreen appears, click **More info → Run anyway**.*

### macOS
1. Download the `.dmg` file.
2. Drag the app into your **Applications** folder.
3. Open and start billing.

### Android
1. Download the `.apk` file on your phone.
2. Allow **Install from Unknown Sources** if prompted.
3. Install and open.

### Linux
1. **AppImage:** Right-click → Properties → Allow executing as program → Double-click.
2. **Debian/Ubuntu:** Run `sudo apt install ./file.deb`.
