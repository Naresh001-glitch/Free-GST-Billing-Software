## 📥 How to Download & Install

Go to the **[Releases](https://github.com)** page and download the file for your device:

* **Windows:** Download `Setup.exe` → Double-click to install → Open from Desktop shortcut. *(If Windows SmartScreen appears, click **More info → Run anyway**).*
* **macOS:** Download the `.dmg` file → Drag the app into your **Applications** folder → Open and start billing.
* **Android:** Download the `.apk` file on your phone → Allow *"Install from Unknown Sources"* if prompted → Install and open.
* **Linux:** Download the `.AppImage` (Right-click → Properties → Allow executing as program → Double-click) or install the `.deb` package via terminal (`sudo apt install ./file.deb`).
